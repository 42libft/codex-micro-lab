# Contributing

Issues and pull requests are welcome for reproducible bugs, protocol observations, and usability improvements.

Before opening a pull request:

1. Run `npm test`.
2. Run the iOS Simulator build if you changed Swift code.
3. Remove pairing tokens, personal paths, device identifiers, and generated build output from logs and screenshots.
4. Explain which Codex build and macOS/iOS versions you tested.

Please keep changes scoped to the hardware-free bridge, the iPhone controller, the protocol notes, or the article. Do not include Codex application binaries or extracted proprietary bundles.
